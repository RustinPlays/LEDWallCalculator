Help

Suggested plans

Suggest Data and Suggest Power are independent. Each creates an efficient left/right snake through the wall, splitting only when a new data port or power chain is required. Use the Data and Power checkboxes above the wall to show either or both plans.

Manual plans

Choose Edit Data or Edit Power, press + Route, then click cabinets in cable order. Press Done when finished. Suggested plans can always be edited or replaced manually.

Front / Back

Back view mirrors the wall so the routing view matches the technician standing behind it. Panel IDs stay attached to the same physical cabinet.

Power & data

Power and pixel figures are planning calculations. Generic panel defaults are editable in equipment-catalog.js; for a real job, replace them with the exact manufacturer values for the cabinet and receiving system you are using.

Save

Save stores the project in this browser. JSON lets you move it to another laptop. Print / PDF uses the browser's print dialog.
